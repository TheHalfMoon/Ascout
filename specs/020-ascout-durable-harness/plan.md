Store one run-specific snapshot named by validated hex run identity only under `<trusted-repository>/.ascout/durable-harness/`. The caller supplies the trusted repository root, never an arbitrary output filename. Validate each managed directory as nonsymlink; create a fixed `.gitignore` with `*` in the state directory using exclusive creation and reject a conflicting existing ignore file. Test actual Git ignored status with owned repository fixtures, including absent root ignore rules. Retain state indefinitely by default with explicit documented operator removal; no auto-purge or expired-record promotion. File limit1MiB, at most256 call records, identifiers/digests bounded; inputs/outcomes contain only digests and enums. Each mutation acquires a new `mkdir` lock, reloads/validates the snapshot, applies an append-only state change, flushes a unique temporary file and atomically replaces the snapshot. Clean only this operation's owned temporary file and newly acquired lock on normal completion. Never remove a preexisting lock; no PID inference/kill. Reads validate complete schema, checksums, identities and terminal-state invariants; no empty fallback. Validate root/files as trusted local nonsymlink objects and document unsupported hostile concurrent path replacement and directory-fsync portability.

Use AssuranceRepositoryIdentityV1's exact existing three-field shape and remote/local portability invariants in the immutable binding. No path/origin hash is computed from untrusted input here: the caller supplies its already captured privacy-safe identity. Reject changed repository identity even when head/tree/configuration/run identities coincide. Include raw credential-bearing origin, malformed identity and portability mismatch cases in the negative contract tests; no raw origin/path reaches the journal.

Use explicit `create` vs `open` to distinguish absent state. Caller supplies expected binding on every open/mutation/recovery. A recorded intent cannot change call name/input/replay/attempt; a terminal outcome cannot be overwritten. Failed work is preserved. Reconciliation and execution remain with existing caller-owned authorities. Add a short documented adapter recipe that records intent before existing authorized work and outcome only after its evidence exists, without constructing commands or publishing.
