# Spec 016 Constitution Delta Assessment

**Status:** `PLANNING_ONLY`
**Planning ledger:** Issue #342

## Assessment

The deterministic Spec 016 first wedge is designed to fit the existing Constitution without amendment.

### Evidence Before Claims

Preserved. Browser runners, recovery logic and agents produce evidence/proposals. Ascout retains claim authority through source-bound evidence and explicit oracle classification.

### No Green by Omission

Preserved. Required browser work that is unavailable, not run, blocked, semantically drifted or missing material evidence cannot disappear behind a clean PASS.

### Source-Bound Truth

Preserved and extended to browser/application/environment identity. Cross-tree evidence transfer remains forbidden.

### Trusted Local Scope and Explicit Authority

Preserved. First browser scope remains developer-owned/trusted-local. Browser actions must not create implicit broad internet-agent authority.

### Native Capability Before Invention

Preserved. Playwright is preferred over browser-protocol reimplementation. Graph databases, browser farms and hosted control planes are rejected for the first wedge.

### Conservative Verification

Preserved. Ambiguous journey/locator mapping widens or fails closed rather than silently deselecting work.

### Bounded, Read-Only, Private Execution

Preserved. Browser execution is bounded, product-source mutation is not implicit, artifacts are sensitive and retained under bounded policy.

### Provenance, Licensing, and Benchmark-Gated Growth

Preserved. Playwright/Momentic reuse requires exact provenance. Agentic/multimodal expansion follows deterministic benchmark evidence.

## Constitutional amendment decision

No Constitution amendment is required for the planned deterministic first wedge.

A future phase MUST re-open this assessment if it proposes any of the following material changes:

- arbitrary untrusted repository or internet execution;
- persistent trust grants;
- hosted/cloud control plane as required core;
- automatic source/test merge authority;
- model-only PASS authority;
- public arbitrary plugin/task execution surface;
- weakening source binding or no-green-by-omission;
- persistent browser/memory service that materially changes trust/privacy boundaries.
