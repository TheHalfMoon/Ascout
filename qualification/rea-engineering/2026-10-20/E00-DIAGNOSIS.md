Measured Git probes on the unchanged first tree-digest case made 129 Git launches. Summed Git time was 12.12–12.57 seconds in 13.47–14.26 seconds wall time, with all four probes passing the existing deadline. No-sampling/20ms/100ms/no-sampling variants differed by less than 0.8 seconds; this does not establish sampling as the primary historical cause. Git process optimization overlaps existing PR614 and hardening overlaps PR589; this mission introduces no competing production repair.

The independent feature reviews did find real defects: cross-package selection could omit a simultaneous source scope, and malformed mutation JSON could cause quadratic token rejection. Both have explicit RED regressions, forward fixes, fresh delta reviews and retained original evidence. Their repairs are isolated in E02/E03.

The two-case traces recorded identical 69/66 synchronous Git calls on both source heads. Summed Git durations consumed about 95% of the cases; no individual call exceeded 333 ms. Publisher timing was 143–228 ms. All seven fixture removals in each capture saw zero active owned child processes, with no EPERM. Source inspection reveals an existing timeout/cancellation ownership gap compatible with earlier cleanup errors, but this replay does not establish that gap as their cause. No speculative cancellation repair is represented as a measured fix. The original local full-suite and recheck failures remain failures; a new complete integrated control is a separate target.
