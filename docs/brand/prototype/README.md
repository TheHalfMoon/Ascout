# Ascout Static Product Prototype

Open `index.html` in a browser.

No build step and no runtime dependency is required.

## Included views

- Home
- Review
- Test
- Security
- Cyber
- Assure
- Lab / Reality
- Evidence Inspector
- Run Timeline
- dark/light mode

## Navigation

Click the left rail, or use:

```text
G then R — Review
G then T — Test
G then S — Security
G then C — Cyber
G then A — Assure
G then L — Lab
```

## Font

The prototype requests `PP Mondwest` by family name but does **not** include the font binary.

If PP Mondwest is not installed/served through an authorized license, the prototype falls back to a monospace font. This is intentional and keeps licensed font files out of the repository.

## Scope

This is a visual/interaction prototype, not production application code.
