1. missing high-value work already researched across TheHalfMoon repositories;

All relevant sources are inputs to a controlled portfolio. Each source receives a disposition such as:

~~~text

~~~

Permission to reuse source permits consideration. It does not bypass exact source pinning, third-party obligations, source/security review, behavioral qualification, or authority boundaries.

## 12. Owner-wide source completion gate

The final implementation plan cannot claim source review completeness until:

1. all accessible TheHalfMoon repositories are enumerated at that time;
2. source/donor/provenance/research ledgers are discovered;
3. material candidates are deduplicated by repository + exact source identity;
4. each candidate is classified against Review/Test/Security/Cyber/Infrastructure/Governance;
5. each receives a disposition;
6. superseded pins are marked historical, not silently replaced;
7. incompatible/copyleft/restricted components receive explicit handling;
8. private/proprietary sources with founder permission still receive provenance and third-party review;
9. source snapshots are re-pinned immediately before intake;
10. all selected sources appear in Ascout's provenance/notices and qualification evidence.

~~~text
SOURCE_PORTFOLIO_CONSIDERED = YES only after owner-wide registry completion
SOURCE_SELECTED_FOR_IMPORT != SOURCE_PORTFOLIO_CONSIDERED
~~~

## 13. Final source strategy

Use sources aggressively for capability and quality, but conservatively for authority.

Preferred order:

~~~text
STUDY
-> ADAPT CONTRACT/METHOD
-> ADAPTER TO MATURE TOOL
-> SELECTIVE REIMPLEMENT
-> SELECTIVE SOURCE PORT
-> WHOLESALE FORK only if benchmark evidence proves it necessary
~~~

The goal is not to maximize imported code.

The goal is to maximize proven capability while keeping Ascout's trust model coherent.
